# 입결 인원 집계·출력 (수시/정시)

`ipsi_report.py`로 시트 캐시에서 조건별 모집인원을 합산·검산해 표로 낸다.
매번 파이썬을 새로 쓰지 말고 이 스크립트를 쓴다.

## 실행 (환경 주의)

`py`가 가리키는 `C:\Python313`에는 pip/site-packages가 없다. **PYTHONHOME은 절대 세팅하지 말 것**
(세팅하면 stdlib 로딩이 깨짐). google 라이브러리는 PYTHONPATH로만 붙인다:

```
Remove-Item Env:\PYTHONHOME -ErrorAction SilentlyContinue
$env:PYTHONUTF8="1"
$env:PYTHONPATH="$env:LOCALAPPDATA\Programs\Python\Python313\Lib\site-packages"
C:\Python313\python.exe ipsi_report.py <인자>
```

캐시(`cache_fact.json`)가 최신이면 그대로, 시트 수정 직후엔 `--refresh`.

## 사용법

```
py ipsi_report.py 대학명="동국대 서울" 학년도=2027,2028 모집기간=수시
py ipsi_report.py 대학명="동국대 서울" 학년도=2028 모집기간=정시 --by=세부전형
py ipsi_report.py 대학명=서울시립대 학년도=2027,2028 모집기간=정시 --refresh
```

- 필터 `key=value` AND, 부분일치. `대학명="동국대 서울"`처럼 공백 토큰 여럿이면 모두 포함(캠퍼스 구분).
- `학년도=2027,2028` → 두 해 + 증감 열. 한 해면 단일 열.
- `--by=` 그룹 컬럼(콤마). 생략 시 **수시=전형유형,세부전형 / 정시=지원군,세부전형** (2컬럼이면 첫 컬럼 소계 자동).
  - 전형유형만: `--by=전형유형` · 세부전형만(군 합산): `--by=세부전형` · 군별: `--by=지원군`
- 출력 끝에 **독립 2경로 검산**(그룹합=독립총합)과 비정수 개수를 자동 표시.

## 사용자에게 낼 때

- 스크립트가 낸 표를 마크다운 표로 정리하고, **"검산 통과 — 그룹합 X = 독립총합 X"**를 짧게 명시(CLAUDE.md 필수 지침).
- 전형유형 라벨은 필요시 축약(학생부위주(종합)→학생부종합 등).
- **전년 대비 특정 세부전형이 사라짐(→ 0/누락)** 이 보이면 폐지인지 시트 미입력인지 원자료 확인을 권장한다.
- **⚠ 수시 오분류 경고**(세부전형에 '군' 표기)가 뜨면 정시 데이터가 수시로 잘못 들어간 것 — 스크립트가 집계에서 제외하며, 삭제/이관 여부를 사용자에게 확인한다.
- 공식 모집요강 수치와 차이가 나면 원인(정원외 특별전형 미반영·특정 학과 누락·전형유형 분류차)을 짚는다.
