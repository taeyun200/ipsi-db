# 파이프라인: 모집인원크롤

어디가 **대학정보 > 모집인원** 페이지(`univDetailRecruit.do`)에서 학년도별 **모집단위별 모집인원**을
전형(계열·전형유형·전형명·전형방법)과 함께 크롤한다. 입결(합격선) 크롤(`엑셀산출.md`)과 **다른 경로**다.

## 크롤 경로 (브라우저 XHR — 로그인 세션 필요, 로그인은 사용자가 직접)

페이지: `https://www.adiga.kr/ucp/uvt/uni/univDetailRecruit.do?menuId=PCUVTINF2000&unvCd=<코드>&searchSyr=2027`
(입결과 달리 `searchSyr=2027`이 곧 2027학년도 모집인원. 입결은 2027 페이지에 2026 결과가 들어있는 것과 다름.)

세 엔드포인트를 쓴다:

| 엔드포인트 | 반환 | 용도 |
|---|---|---|
| `univRecruitAjax.do` | 전형 목록(계열·전형유형·전형명·**전형방법**·학과 바로가기) | 전형별 팝업 파라미터 확보 |
| `univRecruitSubjectPopup.do` | `ul.univList li`에 `모집단위 (N명)` | **모집단위별 모집인원** |
| `univRecruitChangePopup.do` | 2026 vs 2027 전형별 인원 표 | **공식 총계 = 교차검산 기준** |

### 파라미터·함수
- 공통: `unvCd`, `searchSyr`, `pagination.cntPerPage`(전형목록 페이지네이션 — **500으로 전체 한 번에**).
  기본 15행/페이지라 안 키우면 첫 전형유형만 나온다.
- 헤더: `X-Requested-With: XMLHttpRequest`, `X-CSRF-TOKEN`(`meta[name=_csrf]`). 쿠키는 세션 자동첨부.
- **수시/정시/전형기간자율 탭**: 버튼 `onclick="fnChangeTabValue(this,'20'|'30')"` — `fnChangeTabValue(btn,'20')`(수시)/`'30'`(정시). 호출하면 폼 상태 전환 후 재조회.
  (`전형기간 자율` 모집시기는 별도 — 특성화고졸재직자 등이 여기 있음. 탭 코드 확인 필요.)
- **팝업 파라미터**: 전형목록 응답을 페이지 tbody에 주입 → 각 `button[onclick*=fnDetailPopup]`에서
  `fnMkPopupSearchData(btn)` → FormData(`searchSyr·unvCd·aftCd·rcmtMmntCd·slcnGroupCd·ruSn`) → `univRecruitSubjectPopup.do` POST.
  (파라미터가 페이지 전역함수로만 생성돼 응답 HTML 직접 파싱으론 못 얻음 → tbody 주입 + 함수 호출 필수.)

### 파싱
- 전형목록 tr: `td[0]=계열, td[1]=전형유형, td[2]=전형명, td[3]=전형방법`.
- 팝업: `ul.univList li` → `.color-blue` 텍스트가 `(N명)`, 그 앞이 모집단위명. 숫자 없으면(미표기) 빈값.

## 교차검산 (필수) — 학과별 합 ≠ 공식 총계일 수 있다

**학과별 팝업 합계는 `univRecruitChangePopup.do` 공식 총계와 반드시 대조**한다. 가천대 2027 실측 사례:
- 정원내 전형(교과·종합·논술·실기·수능)은 학과별 합 = 공식 세부 **완전 일치**.
- 차이는 세 곳에서만 발생하고 **전부 규명 가능**:
  1. **정원외 학과 미표기** — 재외국민 등은 일부 학과(예 약학·의예)만 인원 표시, 나머지 빈값. 학과별로는 크롤 불가 → 변경사항 팝업의 **전형 총계로 보완**.
  2. **전형기간 자율** — 특성화고졸재직자 등이 수시/정시 탭 밖. 해당 탭 추가 크롤로 보완.
  3. **정시 요약−세부 불일치** — 어디가 원본 자체가 군별합(정시 가/나/다)과 전형별합이 수명 다를 수 있음. 세부(전형별)를 정본으로.
- **매 대학 크롤 합계를 변경사항 팝업 총계와 자동 대조** → 위 누락을 즉시 탐지(독립 2경로 검산).
- 주의: 같은 대학이라도 **페이지마다 총계가 다를 수 있다**(입시결과 요약 vs 모집인원 변경사항). 어느 화면을 정본으로 쓸지 먼저 확정.

## 산출 컬럼
`대학 · 모집기간 · 계열 · 전형유형 · 전형명 · 전형방법 · 모집단위 · 모집인원`

- 전형방법은 **전형명 단위 속성**(모집단위 무관, 대학당 유니크 소수). 형태: 단순(`학생부:100`),
  단계별(`1단계: 학생부:100 / 2단계: 면접:50+1단계성적:50` — 원본은 공백 뭉개짐, 정제 후처리),
  복합(`수능:30 실기:70`). 원본 텍스트 보존, 필요시 후처리.

## 미제출/빈값 처리
- 모집인원 빈값(정원외 학과 미표기)은 산출엔 남기되 **합계·시트반영에서 제외**(시트 0값·빈값 규칙과 동일).
